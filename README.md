# Elevation Hub Interactive

זוהי חבילת אתר סטטית מוכנה להעלאה. אין צורך בהתקנה, בבנייה או בשרת מיוחד.

## העלאה ל-GitHub Pages

1. צרו Repository חדש ב-GitHub.
2. העלו את כל הקבצים שבתיקייה הזו לשורש ה-Repository — חשוב שהקובץ `index.html` יהיה בשורש.
3. היכנסו ל-Settings → Pages.
4. תחת Build and deployment בחרו Deploy from a branch.
5. בחרו את הענף `main` ואת התיקייה `/ (root)`, ואז Save.

## העלאה לשרת אחר

העלו את כל תוכן התיקייה לתיקיית האתר הציבורית של השרת, למשל `public_html`, `www` או תיקיית ה-root שהשירות מספק.

## הערות

- האתר בנוי מ-HTML, CSS ו-JavaScript בלבד.
- התמונות החיצוניות נטענות מ-`https://tanyat-cmd.github.io/elevationhub/`.
- הגופן נטען מ-Google Fonts. ללא חיבור לאינטרנט יוצג גופן חלופי.
